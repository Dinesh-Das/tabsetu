# Changelog

## 1.0.2 - Compliance And Privacy Release

- Removed install-time browser-history access and broad host access.
- Added explicit, revocable opt-in controls for browser-history search.
- Made notification and identity permissions optional.
- Removed saved-URL page fetching from AI prompt sharing.
- Clarified encoded local snapshot sharing and large-session fallback.
- Added privacy, terms, security, store listing, compliance, and release validation documents.
