# 🌌 TabSetu
> **Frosted Luxury for Your Browser. Unlimited Control for Your Tabs.**

TabSetu is a premium, high-performance Chrome extension designed to transform your chaotic browser into a structured productivity sanctuary. Built with a stunning **Glassmorphism UI**, it’s not just a session manager—it’s a workspace orchestrator.

---

## ✨ Key Features

### 🧊 Frosted Glass Experience
*   **Obsidian Precision:** A state-of-the-art Glassmorphism design system that feels native to modern OS aesthetics.
*   **Animated Gradient Mesh:** Dynamic, breathing backgrounds that react to your theme.
*   **Dark/Light/System Mode:** Seamless theme switching with luminous border effects.

### 🗂️ Professional Session Control
*   **One-Click Save:** Snapshot your entire window in milliseconds.
*   **Smart Collapse:** Save all tabs and close the window instantly with a **10-second undo buffer**.
*   **Unlimited Organization:** Categorize sessions with nested Folders and vibrant Tags. No "Pro" limits, ever.

### 🧠 AI & Productivity Powerhouse
*   **AI-Ready Prompts:** Instantly generate context-rich prompts for ChatGPT, Claude, or Gemini from your saved tabs.
*   **Integrated Notes:** Attach notes to specific tabs, entire sessions, or keep standalone research logs.
*   **Smart Reminders:** Set "Remind me in 1 hour" or "Tomorrow at 9 AM" for any tab.
*   **Recurring Schedules:** Auto-open specific tab sets for your daily standup, research hour, or wind-down.

### 🔍 Search Everywhere
*   **Global Search Overlay:** Hit `Ctrl+Shift+F` on any webpage to search your entire TabSetu history without leaving the page.
*   **Fuzzy Logic:** Finds what you need even if you only remember a partial title or URL.

## ⌨️ Supercharge with Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl+Shift+S` | **Save** current window |
| `Ctrl+Shift+C` | **Collapse** (Save + Close) window |
| `Ctrl+Shift+F` | Open **Global Search Overlay** |
| `Ctrl+Shift+D` | Open **TabSetu Dashboard** |
| `Ctrl+K` | Focus Search (inside popup) |

## 🛡️ Privacy & Philosophy

*   **Local-First:** Your data never leaves your computer. No accounts, no cloud tracking, no login required.
*   **Manifest V3:** Built on the latest, most secure extension architecture.
*   **Free Forever:** No hidden tiers. No subscription. No limits on tabs, folders, or sessions.

## 🚀 Getting Started

1.  **Clone the repo:** `git clone https://github.com/Dinesh-Das/tabsetu.git`
2.  **Install dependencies:** `npm install`
3.  **Build:** `npm run build`
4.  **Load in Chrome:** Open `chrome://extensions`, enable **Developer mode**, and click **Load unpacked**. Point to the `dist` folder.
